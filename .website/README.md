# Paint the World

## Story

The world has lost its color. As the last magical unicorn, you must collect the scattered rainbow fragments and bring vibrancy back to the land.

## How to Play

| Key   |       Action       |
| :---- | :----------------: |
| A     |     Move Left      |
| D     |     Move Right     |
| Space |        Jump        |
| Shift | Dash (need unlock) |

-   Collect all rainbow colors
-   Restore color to the world
-   Unlock dash to reach new areas
